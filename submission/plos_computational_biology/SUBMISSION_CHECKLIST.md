# PLOS Computational Biology submission checklist

## Already present

- Full descriptive title.
- Named authors, affiliation and corresponding-author email.
- Structured scientific narrative with eight main figures.
- Author Summary draft.
- Cover letter draft.
- Public-data accession identifiers.
- Data and code availability section.
- Repeated donor-level evaluation and source-only external validation.
- Locked source tables, predictions, methods and checksums.
- Complete initial-submission PDF with Figures 1-8.
- Stable supplementary workbook with worksheets S1-S30.
- Figure legends for every main figure.
- GitHub release tag `v2.0.0-rc3`.
- Clean-directory package validation and SHA256 verification.

## Required before upload

- Confirm author order, contribution statements and approval from all authors.
- Add ORCID identifiers where available.
- Confirm funding statement and competing-interest statement.
- Confirm ethics wording for reanalysis of public de-identified datasets.
- Supply separate high-resolution figure files.
- Link the version-specific Zenodo DOI after the integration creates the record.
- Verify every reference against Crossref, PubMed or the publisher record.
- Select the most suitable journal section and candidate Academic Editor.

## Recommended submission metadata

- **Article type:** Research Article
- **Short title:** Identifiability in patient-level single-cell classifiers
- **Keywords:** single-cell RNA sequencing; patient-level prediction;
  identifiability; study design; batch confounding; external validation;
  foundation models; pseudobulk; systemic lupus erythematosus
