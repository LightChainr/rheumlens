# v2.0.0-rc3 release status

## Scientific status

- The manuscript has been reframed around design-label identifiability in
  patient-level single-cell classification.
- The complete RC2 evidence object is retained.
- Nonlinear design-only prediction and fold-contained random-forest
  residualisation have been added.
- A batch-exposure internal negative control distinguishes design encoding from
  disease-shortcut use.
- Attenuation-difference split-sensitivity intervals, a synthetic positive control
  and a confound-leakage sensitivity experiment have been added.
- The PLOS robustness validator passes 16/16 checks.
