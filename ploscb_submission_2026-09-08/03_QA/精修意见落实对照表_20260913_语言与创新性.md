## 二、减法式语言精修

| 意见 | 落实 |
|---|---|
| 摘要两句拗口（“Such a score is a statement about disease only if …”“separated cohorts a single number would have equated”） | 按建议改为 “A high AUC supports disease-related discrimination only if …” 与 “Similar overall metadata AUCs masked different sources of predictability” |
| 删除元话语：What it does not do is / What this does and does not cover / What that costs is visible / That is the useful result / This deserves a number rather than a caveat / The practical reading is uncomfortable / better published as a number than as a caveat | 正文全部删除或改写为直接陈述 |
| “representation that travels” | 改为 “Increasing model capacity improved fitting to the source cohort but did not improve cross-cohort transfer.” |
| “worth taking seriously as a candidate diagnostic” | 改为 “Together, these evaluations provide stronger evidence for a candidate diagnostic classifier than an internal AUC alone.” |
| 一句只承担一个逻辑功能；长句 | 正文（摘要至 §8）由约 1,140 行压缩到约 830 行（约 27%）；≥50 词的句子逐一拆分，Methods 中 81 词、65 词、60 词等句已拆开 |
| 重复 caveat 集中说一次 | “stratified test 不证明疾病生物学”“restriction 常不可行”“residualisation 与 restriction 回答不同问题”各在一处详细论述，其余处改为交叉引用 |
| 摘要更早强调三类 metadata 的区别 | 摘要第一段即列出 collection / demographics / sample quality 及其不同解释 |
| Methods 中的修订历史（“An earlier version …”） | 三处全部删除，修正经过只保留在逐条回应文件末节 |
