# Version 1.0.0 archival contents

This directory is the self-contained public evidence snapshot for the 17 July 2026 cross-cohort SLE donor-representation manuscript.

- `manuscript/`: complete figure-rich manuscript in Markdown, DOCX, and PDF.
- `figures/svg/`: eleven editable grouped figures with text retained as text.
- `figures/previews/`: PNG review copies.
- `source_data/`: source tables used by the SVG builder, preserving their project-relative provenance.
- `scripts/`: analysis, plotting, and validation scripts.
- `provenance/`: figure-source index, 5090 analysis report, evidence disposition, and visual QA.
- `MANIFEST_SHA256.txt`: SHA256 checksums for every file in this directory.

Primary results are the repeated donor-level benchmark, reciprocal source-only transfer, source-size learning curve, direct cap500 pooling experiment, matched Geneformer cell budgets, and repeated interferon conditioning. Historical fixed-split atlases and covariate branches are explicitly marked as supporting sensitivities.
